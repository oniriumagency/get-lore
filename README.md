# Lore — Descargas

Versiones oficiales de **Lore**, la app de notas inteligente, privada y local-first con sincronización en Google Drive.

## Descargar

Entra a [**Releases**](../../releases/latest) y descarga el archivo de tu plataforma:

| Plataforma | Archivo |
|------------|---------|
| Windows 10/11 (64 bits) | `Lore Notas Inteligentes y Privadas_X.Y.Z_x64-setup.exe` |
| Android 7.0 o superior | `Lore_X.Y.Z.apk` |

## Instalar

**Windows**
1. Ejecuta el instalador `-setup.exe`. No necesita permisos de administrador.
2. Si aparece "Windows protegió su PC", pulsa **Más información** → **Ejecutar de todas formas**.
3. Lore se actualiza sola: cuando haya una versión nueva te mostrará un aviso para instalarla.

**Android**
1. Descarga el `.apk` en tu teléfono y ábrelo.
2. Si te lo pide, permite **Instalar apps desconocidas** para tu navegador o gestor de archivos.
3. Para actualizar, instala el `.apk` nuevo encima del anterior. Tus notas se conservan.
